routes/jobs

Rutas de ofertas de trabajo para Chambaya. Gestiona el CRUD completo de ofertas laborales: creacion, busqueda con filtros, detalle, actualizacion y eliminacion. Tambien maneja las solicitudes de postulacion de los demandantes.

  • routes/jobs.js, line 282

  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${token}` },

    descripcion: 'Necesito alguien para limpiar un piso en el centro...',
    ubicacion: 'Madrid',
    precio: 45,
    tipo_precio: 'fijo',
    categoria_id: 1
