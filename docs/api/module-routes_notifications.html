routes/notifications

Rutas de notificaciones para Chambaya. Gestiona las notificaciones internas de la plataforma: - Notificar al ofertante cuando alguien se postula - Notificar al demandante cuando su solicitud es aceptada/rechazada - Marcar notificaciones como leidas
Description:
  • Rutas de notificaciones para Chambaya. Gestiona las notificaciones internas de la plataforma: - Notificar al ofertante cuando alguien se postula - Notificar al demandante cuando su solicitud es aceptada/rechazada - Marcar notificaciones como leidas
