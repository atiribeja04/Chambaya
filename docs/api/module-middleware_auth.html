middleware/auth

Middleware de autenticacion para Chambaya. Proporciona dos middlewares de Express: - `verificarToken` — extrae y valida el JWT del header Authorization. - `verificarAdmin` — comprueba que el usuario autenticado sea admin.
Description:
  • Middleware de autenticacion para Chambaya. Proporciona dos middlewares de Express: - `verificarToken` — extrae y valida el JWT del header Authorization. - `verificarAdmin` — comprueba que el usuario autenticado sea admin.

Methods

(static) verificarAdmin(req, res, next) → {void}

Description:
  • Verifica que el usuario autenticado tenga el tipo `'admin'`. Debe ejecutarse **despues** de `verificarToken`, ya que necesita los datos del usuario decodificados en `req.usuario`.

Example
router.delete('/usuarios/:id', verificarToken, verificarAdmin, (req, res) => {
  // Solo admins pueden eliminar usuarios
});

(static) verificarToken(req, res, next) → {void}

Description:
  • Verifica que la peticion incluya un token JWT valido en el header `Authorization` con formato `Bearer `. Si el token es valido, decodifica su payload y lo asigna a `req.usuario` para que los siguientes middlewares o rutas puedan acceder a los datos del usuario autenticado.
Source:
  • middleware/auth.js, line 30
Example
router.get('/perfil', verificarToken, (req, res) => {
  res.json({ usuario: req.usuario });
});
