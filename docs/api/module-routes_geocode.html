routes/geocode

Ruta para geocodificar direcciones mediante Nominatim (OpenStreetMap).
Description:
  • Ruta para geocodificar direcciones mediante Nominatim (OpenStreetMap).
Source:
  • routes/geocode.js, line 1

Requires

  • module:express

Methods

(static) geocodeAddress() → {Object|number|number}

Description:
  • POST /api/geocode Convierte una direccion en coordenadas (lat, lng) usando el servicio de geocoding gratuito de Nominatim (OpenStreetMap). Si no se encuentra la ubicacion, devuelve null en ambos campos.
Source:
  • routes/geocode.js, line 10
Example
fetch('/api/geocode', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ direccion: 'Calle Serrano 45', barrio: 'Salamanca', ubicacion: 'Madrid' })
})
Parameters:
Name Type Attributes Description
req.body.direccion string <optional>
 Calle y numero (opcional)
req.body.barrio string <optional>
 Barrio o zona (opcional)
req.body.ubicacion string <optional>
 Ciudad o zona (opcional)
Throws:
Si ocurre un error de red con Nominatim
Type
500

  • 200
    Type
    Object
  • 200.lat - Latitud (o null si no se encontro)
    Type
    number
  • 200.lng - Longitud (o null si no se encontro)
    Type
    number
