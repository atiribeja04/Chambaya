Methods

(static) inicializarBaseDeDatos() → {void}

Description:
  • Crea todas las tablas del esquema si no existen. Tablas creadas: - `usuarios` — Cuentas de usuario (ofertantes, demandantes, admin) - `categorias` — Categorias de ofertas de trabajo - `ofertas` — Ofertas de trabajo publicadas por ofertantes - `valoraciones` — Valoraciones entre usuarios tras un trabajo - `solicitudes` — Solicitudes de postulacion a ofertas Cada tabla incluye sus restricciones CHECK, claves foraneas y valores por defecto. Se ejecuta una unica vez al cargar el modulo.

  • db.js, line 55

// Uso tipico (se ejecuta automaticamente al importar el modulo)
const { db } = require('./db');
